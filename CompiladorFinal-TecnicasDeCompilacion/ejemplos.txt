================================================================
  EJEMPLOS DE ENTRADAS PARA MiSintactico
  Técnicas de Compilación - TC 2026
================================================================

Ubicacion: demo/
Comando:   misintactico "<expresion>"


----------------------------------------------------------------
  1. EXPRESIONES BASICAS
----------------------------------------------------------------

Entrada: a + b
Comando: misintactico "a + b"

Entrada: a * b
Comando: misintactico "a * b"

Entrada: a + b * c
Comando: misintactico "a + b * c"

Entrada: a * b + c
Comando: misintactico "a * b + c"


----------------------------------------------------------------
  2. PARENTESIS
----------------------------------------------------------------

Entrada: (a + b)
Comando: misintactico "(a + b)"

Entrada: (a + b) * c
Comando: misintactico "(a + b) * c"

Entrada: a * (b + c)
Comando: misintactico "a * (b + c)"


----------------------------------------------------------------
  3. RESTA Y DIVISION
----------------------------------------------------------------

Entrada: a - b
Comando: misintactico "a - b"

Entrada: a / b
Comando: misintactico "a / b"

Entrada: (a + b) * c - d
Comando: misintactico "(a + b) * c - d"

Entrada: a + b * c / d - e
Comando: misintactico "a + b * c / d - e"


----------------------------------------------------------------
  4. CON NUMEROS
----------------------------------------------------------------

Entrada: 10 + 20
Comando: misintactico "10 + 20"

Entrada: (5 + 3) * 2
Comando: misintactico "(5 + 3) * 2"

Entrada: x + 10 * y
Comando: misintactico "x + 10 * y"


----------------------------------------------------------------
  5. ENTRADAS INVALIDAS (para probar errores)
----------------------------------------------------------------

Entrada: a + (b * c     (falta parentesis de cierre)
Comando: misintactico "a + (b * c"

Entrada: a +             (operando faltante)
Comando: misintactico "a +"

Entrada: * b + c         (operando izquierdo faltante)
Comando: misintactico "* b + c"

Entrada: a b + c         (falta operador entre a y b)
Comando: misintactico "a b + c"

Entrada: a + * b         (operador consecutivo)
Comando: misintactico "a + * b"


----------------------------------------------------------------
  6. USO CON ARCHIVO
----------------------------------------------------------------

1. Crear archivo (ej: entrada.txt):
   echo (a + b) * c - d > entrada.txt

2. Ejecutar:
   misintactico entrada.txt


----------------------------------------------------------------
  NOTA: Las reglas gramaticales actuales (MiSintactico.g4):
----------------------------------------------------------------

  expr  : expr SUM term  # Suma
        | expr RES term  # Resta
        | term           # Termino

  term  : term MUL factor   # Multiplicacion
        | term DIV factor   # Division
        | factor            # SoloFactor

  factor: ID       # Ident
        | INTEGER  # Entero
        | DECIMAL  # Decimal
        | PA expr PC  # Paren

  Para cambiar las reglas, editar:
    src/main/antlr4/com/compilador/MiSintactico.g4

  Luego recompilar con:
    mvn compile -q
